# SMDA Flutter App

This folder holds the Flutter client. Initialize it with:

```bash
flutter create . --project-name smda_app
```

Then point API calls to the backend at `http://localhost:8000` (see root `README.md` → Quick Start).

Suggested screen list (see `docs/user-stories.md` and Figma wireframes):
1. Onboarding / Login
2. Symptom Intake (questionnaire/chat)
3. Triage Result (urgency + possible conditions)
4. Symptom History / Timeline
5. Shareable Summary (for clinician)
6. Profile / Settings
